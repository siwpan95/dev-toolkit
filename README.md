# pdf

简易 PDF 阅读器 —— 基于 PyMuPDF 与 Pillow 的 Tkinter 桌面 PDF 阅读器，附若干物理教材 PDF 样本。

## 语言 / 类型
- Python（Tkinter GUI）

## 目录要点
- `main.py` —— GUI 入口（打开 PDF、翻页、缩放显示）
- `title/` —— 示例 PDF（朗道理论物理教程等 11 本）
- `requirements.txt` —— 依赖声明

## 运行方式与依赖
- 运行：`F:\Python314\python.exe main.py`
- 依赖：`PyMuPDF`（fitz）、`Pillow`。
