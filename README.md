# renamer —— 正则批量重命名工具

> 仓库：<https://gitee.com/siwpan/renamer> ｜ 许可：MIT（见 [LICENSE](LICENSE)）
> 注：文中 <PATH> 为路径占位符，请替换为你本机实际的目录 / 可执行文件路径。

一个**自包含**的桌面小工具，用正则表达式对文件夹内的文件进行批量重命名。
图形界面基于 Tkinter（中文 UI），核心逻辑纯标准库实现，无第三方依赖。

> 设计原则：**复制优于共享**。本工具完全独立运行于 `<PATH>`，
> 不 import 其它工具目录，也不依赖任何中心化共享核。

---

## 功能特性

- **正则替换**：输入 `pattern`（正则表达式）与 `repl`（替换模板），
  支持分组引用 `\1` `\2` 等 Python `re.sub` 语法。
- **实时预览**：输入即刷新「旧名 → 新名」列表，不改动任何文件。
- **风险标红**：自动检测并以红色标记以下危险情况：
  - `冲突`：多个文件映射到同一新名。
  - `空名`：替换后新名为空。
  - `会覆盖`：新名会被已存在且不会被腾空的条目占用。
  - `非法字符`：新名含 Windows 非法字符 / 保留设备名 / 首尾空格或点。
- **默认 dry-run**：不勾选「执行重命名」时，无论如何都只预览、不改文件。
- **安全执行**：只有勾选「执行重命名」且**预览零风险**时，执行按钮才可点击；
  一旦存在冲突/覆盖等风险，一律阻止并提示。
- **默认不递归**：默认只处理当前文件夹；可勾选「递归子目录」。
- **跳过占用文件**：重命名时若文件正被占用 / 无权限，自动跳过并继续其余文件。
- **防相互覆盖**：采用临时分级重命名，链/环式重命名（如 `a→b, b→a`）也能安全完成。

## 运行方式

1. 确保已安装 Python 3.8+（含 Tkinter）。
2. 双击或在命令行运行：
   ```bash
   python main.py
   ```
   或在 Windows 上直接用 `python.exe main.py`。
3. 在界面中：
   - 点击「选择文件夹」选定目标目录；
   - 填写 `pattern` 与 `repl`；
   - 实时查看预览列表，红色行代表不可执行的风险；
   - 确认无误后，勾选「执行重命名」，点击「开始重命名」。
4. 不勾选「执行重命名」时，工具**永远不会改动磁盘**，可放心试验。

## 核心函数（core.py）

### `preview_renames(folder, pattern, repl, recursive=False) -> list[dict]`

预览重命名结果（dry-run，不改动文件）。

- 参数
  - `folder`：目标文件夹路径
  - `pattern`：正则表达式字符串
  - `repl`：替换模板（支持 `\1` 等分组引用）
  - `recursive`：是否递归子目录（默认 `False`）
- 返回：每个文件一个字典 `{old, new, status, path}`
  - `status ∈ {'ok','conflict','empty','overwrite','invalid'}`
- 异常：`pattern` 不合法时抛出 `re.error`，由 GUI 捕获提示。

### `apply_renames(preview, only_status='ok') -> (done, skipped)`

根据预览结果执行实际重命名。

- 参数
  - `preview`：`preview_renames` 的返回值
  - `only_status`：只执行该状态的条目（默认 `'ok'`；风险状态天然被跳过）
- 返回：`(done, skipped)`，分别为成功数与跳过数。
- 安全：双保险检测目标存在、临时分级重命名、捕获 `OSError` 跳过占用文件。

## 使用示例

将 `a_1.txt`、`a_2.txt` 重命名为 `b_1.txt`、`b_2.txt`：

- `pattern` = `a_(\d+)`
- `repl`    = `b_\1`

预览将显示：

| 原文件名 | 新文件名 | 状态 |
|----------|----------|------|
| a_1.txt  | b_1.txt  | 可重命名 |
| a_2.txt  | b_2.txt  | 可重命名 |

勾选「执行重命名」后点击「开始重命名」即可生效。

## 已知限制

1. **只重命名文件，不重命名文件夹**：目录名不会被正则改写（避免破坏目录结构）。
2. **仅 Windows 非法字符校验**：`has_illegal_chars` 按 Windows 规则判定；
   在 Linux/macOS 上运行不会报错，但可能生成跨平台非法文件名。
3. **环式/链式重命名安全但不可逆**：如 `a→b, b→a` 会通过临时文件安全完成，
   但执行后无法自动撤销，请在执行前确认预览正确。
4. **无撤销功能**：重命名是破坏性操作，执行前请务必确认；建议对重要文件先备份。
5. **跨目录移动不支持**：`repl` 中若出现路径分隔符会被判为非法字符，
   本工具只在同一目录内重命名，不做跨目录移动。
6. **超大目录性能**：预览会一次性载入目录全部文件，极大量文件时界面可能短暂卡顿。
